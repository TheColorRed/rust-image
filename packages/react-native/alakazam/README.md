# @alakazam/mobile

React Native bindings for abra, generated by
[uniffi-bindgen-react-native](https://github.com/jhugman/uniffi-bindgen-react-native)
using its `jsi2` flavour: this package ships `libalakazam_mobile.so` plus
TypeScript, and the app's `@ubjs/react-native` player loads it at runtime.

## Prerequisites

- `rustup target add aarch64-linux-android x86_64-linux-android`
- `cargo install cargo-ndk`
- Android SDK with an NDK and the SDK's CMake package (SDK Manager → SDK Tools)

## Building

```sh
npm run build-bindings:android            # from the repo root
npm run build:android -- --release        # from this package; args go to ubrn
npm run build:android -- --targets arm64-v8a
```

This builds the crate per ABI into `android/src/main/jniLibs/` (gitignored) and
regenerates `src/index.tsx`, `src/generated/`, `android/` and the podspec. The
first run also compiles the `ubrn` CLI.

`scripts/build-android.mjs` exists because abra's JPEG support compiles
libjpeg-turbo with CMake, which needs the NDK toolchain file and Ninja when
cross-compiling. It sets those through target-scoped `CMAKE_*_<triple>` env
vars so desktop builds are unaffected.

After changing the Rust API, rebuild and restart Metro. After adding the
package to an app, rebuild the app (`npx expo run:android`).

## Using it

The app must depend directly on `@ubjs/react-native` and `@ubjs/core`, run the
New Architecture, and ship only `arm64-v8a`/`x86_64` (the ABIs the player
ships).

```ts
import { AbraImage } from '@alakazam/mobile';

const image = AbraImage.read('/data/user/0/…/cache/photo.jpg'); // a path, not a file:// URI
image.brightness(40);
image.gaussianBlur(8);
image.write('/data/user/0/…/cache/photo-edited.png');
```

Calls are synchronous and run on the JS thread.
