# YOLO26n-seg model

`yolo26n-seg.onnx` is the Ultralytics YOLO26 nano instance-segmentation model, redistributed from
[`prithivMLmods/YOLO26-ONNX`](https://huggingface.co/prithivMLmods/YOLO26-ONNX/tree/main/yolo26n-seg) under AGPL-3.0.
The model detects people as COCO class 0 and produces an instance mask for each detection.
