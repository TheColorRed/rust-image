# Settings

Open the **Settings** tab at the bottom of the home screen. The tabs aren't shown while you're editing a photo, so close the editor first. The settings are in three cards: **Display**, **Export** and **Performance**.

Each setting is a row of choices. Tap one to pick it, and the chosen one is highlighted. Your choices are saved, so they're still there the next time you open Alakazam.

Next to each setting's name there is a small **?** icon. Tap it for a short explanation, and tap anywhere to close it.

## Display

### Appearance

Whether the app is light or dark.

| Choice | What it does |
| --- | --- |
| **System** | Follows your phone's light or dark setting. This is the starting choice. |
| **Light** | Always light. |
| **Dark** | Always dark. |

## Export

The export settings decide the file you get when you **Share** a finished photo. See [Projects](/guide/projects#share-your-photo).

### Export format

The type of file your photo is saved as when you share it.

| Choice | What it is for |
| --- | --- |
| **WebP** | Smaller files with the same looks. This is the starting choice. |
| **JPEG** | Works in every app, so pick it if an app can't open WebP. |
| **PNG** | Keeps every detail, but makes the biggest file. |

### Export quality

How much detail a shared photo keeps. Better looks make a bigger file.

| Choice | What it does |
| --- | --- |
| **Good** | The smallest file, with a little less detail. |
| **Better** | A good balance of detail and size. This is the starting choice. |
| **Best** | The sharpest result and the biggest file. |

Quality has no effect on **PNG**, since PNG doesn't lose any detail.

## Performance

### Photo processing memory

How much working room each photo job gets: **4 MB**, **8 MB**, **16 MB**, **32 MB** or **64 MB**. The starting choice is **16 MB**.

You can leave this alone. If the app closes by itself while it prepares a photo, try a bigger size. A bigger size uses more of your phone's memory, so go up one step at a time.

The change doesn't happen right away. It starts working the next time you open the app, so close Alakazam completely and open it again. After you pick a new size, a yellow note, **Reopen the app to apply**, appears beside the **?** icon. If you change your mind and pick the size the app is already using, the note goes away.

## AI models are in Plugins

AI models and add-ons aren't managed here. Use the **Plugins** tab to see, download and delete them. See [Plugins](/guide/plugins).
