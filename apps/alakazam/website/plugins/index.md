# Plugin docs

Plugins add features to Alakazam after you install them. Some plugins ship with Alakazam's catalog and some you write yourself.

## Built-in plugins

| Plugin | What it adds |
| --- | --- |
| [Beauty](/plugins/beauty) | Skin, makeup, teeth, red eye, blemish and hair controls in the Beauty tab. |
| [Object Remover](/plugins/object-remover) | The Remove Objects tool in the Cleanup tab. |
| [Collage](/plugins/collage) | A workspace that builds one image from several photos. |

## Using plugins

Open **Plugins** from the home screen to download, update or delete plugins, or to install one from an `.akzx` file. See [Plugin management](/guide/plugins).
