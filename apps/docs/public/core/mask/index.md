# Mask Overview

Masks control visibility and effect strength on a per-pixel basis. White mask values mean fully visible or fully affected, black means hidden or unaffected, and gray values provide partial strength.

## Mask guides

| Guide            | Covers                                                                     |
| ---------------- | -------------------------------------------------------------------------- |
| [Masks](./masks) | Create masks, draw mask areas, apply masks, and convert RGBA to grayscale. |

Masks are also used by [Apply options](../apply-options) to limit adjustments and filters with a grayscale image.
