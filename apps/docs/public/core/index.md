# Core Overview

The Abra core documentation covers the foundational image-processing APIs: adjustments, canvases, colors, drawing, filters, geometry, images, masks, and transforms.

## Core sections

| Section                          | Covers                                                            |
| -------------------------------- | ----------------------------------------------------------------- |
| [Adjustments](./adjustments/)    | Tone, color, exposure, opacity, and palette operations.           |
| [Canvas](./canvas/)              | Layered composition, positioning, transforms, and effects.        |
| [Color](./color/)                | RGBA colors, fills, gradients, and histograms.                    |
| [Filters](./filters/)            | Blur, sharpen, noise, edge, smoothing, and distortion operations. |
| [Geometry](./geometry/)          | Points, paths, areas, strokes, shapes, and viewbox mapping.       |
| [Drawing](./drawing/)            | Fills, brushes, painter contexts, and rasterized drawing.         |
| [Typography](./typography/)      | Font loading, text layout, and rasterized text rendering.         |
| [Masks](./mask/)                 | Grayscale visibility masks and per-pixel effect strength.         |
| [Image](./image/)                | Raster construction, pixels, file I/O, and image collections.     |
| [Transforms](./transform/)       | Resize, crop, rotate, flip, and interpolation algorithms.         |
| [Settings](./settings)           | Global initialization and optional GPU behavior.                  |
| [Utilities](./utilities)         | Small conversion and selection helpers for integrations.          |
| [Apply options](./apply-options) | Restrict supported adjustments and filters to areas or masks.     |

Start with [Getting started](../getting-started/) for installation and first workflows.
